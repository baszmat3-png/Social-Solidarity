# تكافل — منصة إدارة العمل الخيري

واجهة عربية (RTL) + خادم Express + تخزين Postgres (أو ملف JSON محلياً).

## التشغيل محلياً
```bash
npm install
cp .env.example .env   # ثم عدّل البيانات
export $(cat .env | xargs) && npm start
```
افتح http://localhost:3000 — الدخول: `ADMIN_EMAIL` / `ADMIN_PASSWORD` (الافتراضي `admin@takaful.local` / `ChangeMe123`).

## الرفع إلى GitHub
```bash
git init && git add . && git commit -m "Takaful v2.0.0"
git branch -M main
git remote add origin https://github.com/USERNAME/takaful.git
git push -u origin main
```

## النشر على Render
1. Render ← **New → Blueprint** ← اختر المستودع (يقرأ `render.yaml` ويُنشئ الخدمة وقاعدة Postgres).
2. أدخل `ADMIN_EMAIL` و `ADMIN_PASSWORD` عند الطلب.
3. بعد النشر افتح الرابط وسجّل الدخول.

> ملاحظة: قاعدة Postgres المجانية في Render تنتهي بعد 30 يوماً. للإنتاج استخدم خطة مدفوعة،
> أو ضع `DATABASE_URL` لقاعدة خارجية (Neon / Supabase) مع `PG_SSL=true`.
> بدون `DATABASE_URL` تُحفظ البيانات في ملف مؤقت يُمسح عند إعادة تشغيل الخدمة المجانية.

## الأقسام (كلها تعمل)
المستخدمون، قوالب الصلاحيات (62 صلاحية)، التصنيفات، المناطق، العائلات، المستفيدين، المتبرعين، الصناديق، تدوير الأموال، التبرعات (مع وصولات وطباعة)، الصرفيات، الحملات، المشاريع، التقارير (8 تقارير + تصدير Excel وطباعة PDF)، سجل العمليات، إعدادات الوصولات، إعدادات العرض العام، الإشعارات وإعداداتها، الواجهة العامة (الحملات/المشاريع/التحقق من التبرع).
- الحذف «ناعم» ويمكن استعادته من قائمة «المحذوفة».
- الأموال المقيّدة بحملة لا تُصرف ولا تُدوَّر إلا على تلك الحملة/مشاريعها.
- كلمات مرور المستخدمين مشفّرة (scrypt) والصلاحيات تُفرض على الخادم أيضاً.
- إشعارات الجهاز تعمل بينما المتصفح/التطبيق مفتوح (Web Notifications)؛ الإشعار وهو مغلق يحتاج خدمة Push مستقلة.

## نقاط الـ API
| المسار | الوصف |
|---|---|
| `POST /api/login` | تسجيل الدخول ← `token` |
| `GET /api/public` | حملات ومشاريع عامة |
| `POST /api/verify` | التحقق من تبرعات برقم الهاتف أو رقم الوصل |
| `GET/PUT /api/state` | حالة النظام (يتطلب تسجيل الدخول) |
| `GET /healthz` | فحص الصحة |
